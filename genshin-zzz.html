Макросы и автоматизация могут нарушать правила игры и привести к ограничениям или блокировке аккаунта. Проверяй актуальные правила каждой игры. Использование — на твой риск.

Что Потребуется

  • Windows 10/11
  • В исходной инструкции указан AutoHotkey v1.1 — перед установкой сверь требование с README выбранного проекта.

Официальный сайт: www.autohotkey.com

Общий Порядок Установки

  1. Открой страницу проекта и внимательно прочитай README и раздел Releases.
  2. Проверь требования и совместимость версии AutoHotkey.
  3. Скачивай файлы только из репозитория разработчика.
  4. Не запускай незнакомые скрипты с правами администратора без необходимости.
  5. Если не уверен в содержимом файла, не запускай его.

Безопасность

Не отключай антивирус ради запуска скрипта и не вводи данные аккаунта в сторонние инструменты.

Важно: сторонние репозитории могут измениться, стать недоступными или содержать рискованные файлы. Наличие ссылки не означает одобрение проекта.
