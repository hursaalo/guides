Minecraft — свой сервер бесплатно за 20 минут

Aternos: создание, whitelist, плагины, вылеты, сохранение мира.

Свой сервер для себя и друзей без оплаты и без выделенного ПК: создание, запуск, плагины, доступ только для своих, вылеты и лаги.

> Важно: условия бесплатного хостинга меняются. Актуальные лимиты смотри в панели Aternos. Этот гайд — пошаговая инструкция, а не гарантия, что сервер выдержит любую нагрузку.

Что получишь и чего ждать

  • Сервер бесплатный, его оплачивает реклама на сайте панели.
  • Подходит для компании примерно 5–15 человек. Для большего онлайна нужен платный хостинг.
  • Перед запуском бывает очередь (днём иногда 20–30 минут). Сервер сам выключается, когда выходит последний игрок.
  • Оперативная память и место ограничены (порядка 2 ГБ ОЗУ и 4 ГБ хранилища). Тяжёлые сборки и огромные карты не потянет.

1. Создание сервера

  1. Открой aternos.org и зарегистрируйся (почта и пароль).
  2. Нажми «Создать сервер», выбери Java (для ПК) или Bedrock (для телефонов и консолей).
  3. Дай имя серверу, выбери версию игры. Версия сервера должна совпадать с версией твоего клиента.
  4. Нажми «Запустить», дождись очереди. Когда статус «Онлайн», скопируй адрес сервера из панели.
  5. В игре: Сетевая игра → Добавить сервер → вставь адрес.

2. Доступ только для своих (whitelist)

  1. В панели открой раздел «Игроки» → «Белый список».
  2. Добавь ники друзей (для Java ник должен совпадать с лицензионным или тем, под которым заходят).
  3. Включи whitelist в «Опциях» сервера и перезапусти его.
  4. Чтобы дать права администратора себе: «Игроки» → «Операторы» → добавь свой ник.

3. Плагины и команды (Paper)

  1. В «Программное обеспечение» выбери Paper: на Vanilla плагины не работают.
  2. Открой раздел «Плагины» и ставь только из каталога панели. Загрузить свой .jar нельзя.
  3. Полезный минимум: защита построек (например, GriefPrevention), права игроков, телепорты и дома.
  4. После установки плагина перезапусти сервер. Команды плагинов вводятся в игре с /, а консоль доступна в панели.

4. Если друзья заходят с телефона

  • Для Java-сервера с мобильными друзьями нужен плагин Geyser (из каталога панели, если он доступен для твоей версии).
  • Проще: сразу создай сервер Bedrock, если играют только с телефонов и консолей.

5. Вылеты и лаги: что проверить

  • Сервер пишет «Нет места»: удали лишние миры и плагины, оставь один мир.
  • Лаги при большом онлайне: уменьши дальность прорисовки сервера, убери тяжёлые плагины.
  • «Версия несовместима»: версия клиента и сервера должны совпасть.
  • Не заходит друг: проверь whitelist и адрес (без пробелов), попроси перезапустить игру.

6. Сохранение мира

  • Периодически скачивай мир из раздела «Мир» (файл-архив), чтобы не потерять постройки.
  • Перед сменой версии сервера обязательно сделай копию.

Правила

  • Читы, X-Ray и нарушающие правила моды на твоём сервере решаешь ты, но на чужих серверах за них банят. Этот гайд — про свой сервер для друзей.
  • Не отдавай пароль от панели посторонним: доступ к серверу выдавай через «Доступ» в панели.
