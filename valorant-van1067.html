Valorant — ошибка VAN 1067 / TPM 2.0

TPM и Secure Boot в BIOS по шагам для Intel и AMD.

Что это за ошибка

  • VAN 1067 — античит Vanguard на Windows 11 требует включённые TPM 2.0 и Secure Boot (безопасную загрузку).
  • Игра не запустится, пока оба пункта не включены в BIOS. Переустановка игры здесь не поможет.

Шаг 1. Проверь, что сейчас включено

  1. Win + R → msinfo32 → Enter.
  2. Найди строку «Состояние безопасной загрузки»: нужно «Вкл.».
  3. Win + R → tpm.msc → Enter. Должно быть «TPM готов к использованию», версия спецификации 2.0.
  4. Если оба пункта уже включены — сразу переходи к шагу 4.

Шаг 2. Включи TPM в BIOS

  1. Перезагрузи ПК и жми Del (на ноутбуках часто F2), пока не откроется BIOS.
  2. Включи Advanced Mode (обычно клавиша F7).
  3. Найди TPM — он называется по-разному:
  • Intel: PTT (Intel Platform Trust Technology) → Enabled.
  • AMD: fTPM (AMD fTPM switch) → Firmware TPM / Enabled.
  1. Где искать: MSI — Settings → Security → Trusted Computing; ASUS — Advanced → PCH-FW Configuration или AMD fTPM; Gigabyte — Settings → Miscellaneous.

Шаг 3. Включи Secure Boot

  1. В BIOS: вкладка Boot → CSM (Compatibility Support Module) → Disabled. Без этого Secure Boot не включится.
  2. Secure Boot → Enabled. Если просит ключи — выбери Install default keys / Restore Factory Keys.
  3. F10 → сохранить и перезагрузиться.
  • Важно: отключать CSM безопасно, только если Windows стоит на диске GPT. Проверка: Win + X → «Управление дисками» → ПКМ по диску → Свойства → Тома → «Стиль раздела». Если там MBR — сначала конвертируй: в командной строке от администратора mbr2gpt /validate /allowFullOS, затем mbr2gpt /convert /allowFullOS. Без этого система не загрузится.

Шаг 4. Если всё включено, а ошибка осталась

  1. Win + R → services.msc → найди vgc → «Тип запуска» → Автоматически → Запустить.
  2. Перезагрузи ПК (Vanguard стартует только при загрузке Windows).
  3. Удали Riot Vanguard через «Приложения», перезагрузись, запусти Valorant — он сам переустановит античит.
  4. Обнови BIOS с сайта производителя материнки, если TPM в нём не находится вообще.

Частые вопросы

  • Ошибка VAN 9001 — то же самое, решается теми же шагами.
  • Слетела ли Windows после включения? Нет, если диск GPT. Файлы не трогаются.
  • На Windows 10 нужно? Нет, там TPM и Secure Boot для Vanguard не обязательны — ищи другую причину (шаг 4).
