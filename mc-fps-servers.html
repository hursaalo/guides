Minecraft — FPS + красота для FunTime / HolyWorld / ReallyWorld

Sodium, Embeddium, шейдеры для слабых ПК, настройки PvP.

Цель: стабильные 144+ FPS в PvP и при этом не «квадратная» картинка. Подходит для слабых ПК и ноутбуков.

Какую версию ставить

  • Посмотри версию сервера на его сайте или в лаунчере (у FunTime, HolyWorld, ReallyWorld бывают режимы и на 1.16.5, и на 1.21+).
  • 1.21.x → Fabric + Sodium (раздел A).
  • 1.16.5 → Forge + Embeddium + Oculus или OptiFine (раздел B).

A. Версия 1.21.x (Fabric)

  1. Установщик Fabric: fabricmc.net/use/installer → выбери свою версию → Install.
  2. В %appdata%\.minecraft\mods положи (Modrinth, версия под твою игру):
  • Fabric API, Sodium, Lithium, FerriteCore, Entity Culling, ImmediatelyFast, ModernFix.
  • Для шейдеров: Iris + шейдер MakeUp Ultra Fast (слабый ПК) или Complementary Reimagined (мощный).

B. Версия 1.16.5 (Forge)

  1. files.minecraftforge.net → 1.16.5 → Installer → Install client.
  2. В mods: Embeddium (аналог Sodium для Forge), Entity Culling, FerriteCore.
  3. Шейдеры: Oculus + MakeUp Ultra Fast.
  • Альтернатива попроще: OptiFine 1.16.5 с optifine.net (только официальный сайт, кнопка «Mirror»).

Настройки видео для PvP

  • Дальность прорисовки: 6–10, дальность симуляции: 5.
  • Графика: Быстрая, облака Выкл, мягкое освещение Выкл (на слабом ПК).
  • Частицы: Уменьшено (меньше лагов в замесах, но удары видно).
  • Макс. FPS: Неограниченно, вертикальная синхронизация Выкл.
  • FOV: 90–100, эффекты FOV (скорость) — 0%, покачивание камеры Выкл.
  • Sodium/Embeddium → «Производительность»: всё Вкл, «Использовать без блокировки» — Вкл.

Красота без потери FPS

  • Ресурспак 16x PvP (на Modrinth: раздел Resource Packs, фильтр «pvp»). Низкие мечи и прозрачный огонь — меньше закрывает экран.
  • Моушн-блюр (Natural Motion Blur) — только если FPS выше 120, иначе будет «мыльно».
  • Шейдер MakeUp Ultra Fast → профиль Low: красивое небо и вода при минимальной просадке.

Выделение памяти

  • Лаунчер → Настройки профиля → JVM-аргументы: -Xmx4G при 8 ГБ ОЗУ, -Xmx6G при 16 ГБ. Больше 8 ГБ не ставь — станет только хуже.
  • Закрой браузер и Discord-оверлей перед игрой.

Правила серверов

  • Всё в этом гайде — оптимизация и визуал, это разрешено. Читы, X-Ray, фулбрайт, «киллауры» — бан на всех трёх серверах навсегда, не рискуй аккаунтом.
  • «Сборки FunTime с бесплатными читами» с непонятных сайтов почти всегда содержат стилер.
