Реферат по ГОСТ — чек-лист

Поля, шрифт, нумерация, источники в Word за 10 минут.

Основа — ГОСТ 7.32-2017 и типовые требования школ и вузов. Сначала проверь методичку своего учителя/кафедры — если там другое, делай как в методичке.

Страница

  • Поля: левое 30 мм, правое 15 мм, верхнее и нижнее 20 мм.

Word: Макет → Поля → Настраиваемые поля.

  • Шрифт Times New Roman 14, цвет чёрный.
  • Межстрочный интервал 1,5, выравнивание по ширине, абзацный отступ 1,25 см.

Word: Главная → Абзац (стрелочка в углу) → «Первая строка: отступ 1,25», «Интервал: 1,5», «Перед/после: 0».

Нумерация страниц

  • Внизу по центру, арабскими цифрами. На титульном листе номер не ставится, но он считается первым.

Word: Вставка → Номер страницы → Внизу страницы → по центру; затем Колонтитулы → «Особый колонтитул для первой страницы».

Структура

  1. Титульный лист
  2. Содержание
  3. Введение (актуальность, цель, задачи)
  4. Основная часть (главы 1, 2…)
  5. Заключение (выводы по задачам)
  6. Список использованных источников
  7. Приложения (если есть)

Каждый из этих разделов — с новой страницы (Ctrl+Enter).

Заголовки

  • «ВВЕДЕНИЕ», «ЗАКЛЮЧЕНИЕ», «СОДЕРЖАНИЕ» — прописными, по центру, без точки.
  • Главы: «1 Название главы» — с абзацного отступа, без точки в конце.
  • Назначь заголовкам стиль «Заголовок 1/2» → Ссылки → Оглавление соберёт содержание автоматически.

Рисунки и таблицы

  • Подпись рисунка снизу по центру: «Рисунок 1 — Название».
  • Название таблицы сверху слева: «Таблица 1 — Название».
  • В тексте обязательно ссылка: «(рисунок 1)», «в таблице 1».

Список источников (примеры)

  • Книга: Иванов, И. И. Название книги / И. И. Иванов. — Москва : Издательство, 2023. — 250 с.
  • Сайт: Название страницы. — Текст : электронный // Название сайта : [сайт]. — URL: https://... (дата обращения: 01.10.2026).

Финальная проверка

  • поля и шрифт ☐ интервал 1,5 и отступ 1,25 ☐ номера страниц, на титуле нет ☐ разделы с новой страницы ☐ оглавление обновлено (ПКМ → Обновить поле) ☐ подписи рисунков и таблиц ☐ источники оформлены и пронумерованы
