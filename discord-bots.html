Права При Приглашении

Давать:

  • Manage Roles
  • Manage Channels
  • Kick / Ban / Timeout (только модерационным)
  • Manage Messages
  • Read Message History
  • Send Messages + Embed Links
  • Add Reactions
  • View Audit Log (Dyno, Wick)
  • Connect + Speak (музыка)

НЕ давать Administrator.

Если бота взломают — с админкой он снесёт сервер.

Роль бота:

выше ролей участников, ниже владельца и админов.

Реакции не выдают роль → роль бота слишком низко.

  1. CARL-BOT — роли и автомод
  1. carl.gg → Login with Discord → Add to Server
  2. Дашборд → ваш сервер
  3. Роли по реакциям:
  • канал #roles
  • сообщение: «нажми эмодзи — получи роль»
  • Carl-bot → Reaction roles → New
  • эмодзи → роль → Save
  1. Автомод:
  • инвайты чужих серверов, спам, массовые упоминания
  • действие: удалить + таймаут
  1. Welcome (если не ставите отдельный welcome-бот):
     {user.mention} прочитай #rules и возьми роль в #roles

  2. DYNO — модерация и логи
══════════════════════════════════════════════════

  1. https://dyno.gg  → Add to Server
  2. Включить модули:
     Moderation · Action Log · Automod · Tickets
     (Tickets — если не ставите Ticket Tool)
  3. Action Log → канал #logs  (только модеры)
     писать: баны, кики, таймауты, удаления, входы
  4. Автомод: капс, спам, инвайты от обычных участников
     + свой список запрещённых слов
  5. Назначить роль Moderator
     команды: /mute  /warn  /ban


══════════════════════════════════════════════════
  3. TICKET TOOL — тикеты поддержки
══════════════════════════════════════════════════

  Не ставьте Ticket Tool И Dyno Tickets сразу — будут двойные тикеты.
  Выберите один.

  1. https://tickettool.xyz  → Add to Server
  2. Категория TICKETS (пустая)
  3. Канал #support — все видят, пишет только бот
  4. Dashboard → Panels → New
     кнопка «Открыть тикет»
     открывать в категории TICKETS
     staff-роли: Moderator, Admin
  5. Транскрипты закрытых тикетов → #ticket-logs (только staff)
  6. Проверка: кнопка создаёт приватный канал

  6. МУЗЫКА
══════════════════════════════════════════════════

  Главный: Jockie Music
  https://www.jockiemusic.com

  Почему он:
  • бесплатный
  • Spotify, Apple Music, Deezer, SoundCloud, радио
  • до 4 копий на одном сервере = 4 войса с разной музыкой

  Команды:
    m!play  название или ссылка
    m!skip
    m!queue
    m!stop
    m!invite     ← добавить Jockie 2 / 3 / 4

  Запасной: FredBoat   https://fredboat.com
  С дашбордом: Green-bot   https://green-bot.app
  Лёгкий: Chip   (App Directory → Chip)

  Ставьте ОДИН музыкальный бренд. Jockie + Chip в одном войсе =
  две песни сразу.

  Права музыке: Connect + Speak. Без Administrator.

  За 5 минут:
  1. Войс Music + текст #music-commands
  2. Пригласить Jockie с официального сайта
  3. Зайти в войс →  /play  или  m!play
  4. Несколько войс-комнат с музыкой → m!invite

  YouTube-ссылки у ботов в 2026 часто не играют.
  Кидайте Spotify / Apple Music / SoundCloud.

  Без бота: Discord → Настройки → Связанные аккаунты → Spotify
  → Listen Along. Работает только если у людей Spotify Premium.

──────────────────────────────────────────────────
  ТИПИЧНЫЕ ОШИБКИ
──────────────────────────────────────────────────

  • Роль бота ниже роли, которую он должен выдавать
    → реакции не работают
  • @everyone видит #logs и категорию TICKETS
    → приватность сломана
  • Два тикет-бота сразу
    → двойные тикеты
  • Administrator у каждого бота
    → один взлом = мёртвый сервер
  • Фичи MEE6 Premium на бесплатном плане
    → просто не включатся
  • Groovy / Rythm / «бесплатный YouTube»
    → бот мёртвый или завтра забанят
  • Бот в войсе, звука нет
    → нет права Speak, или вы в наушниках deafen
  • Две песни сразу
    → два музыкальных бота в одном войсе
