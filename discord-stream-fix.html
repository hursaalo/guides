Discord — не видит игру / чёрный экран

8 решений по шагам: демонстрация, звук, ноутбуки.

Иди по шагам сверху вниз. После каждого шага проверяй, помогло ли.

1. Добавь игру вручную

Настройки пользователя → Зарегистрированные игры (Activity Privacy / Registered Games) → «Добавить» → выбери процесс игры. Включи значок оверлея рядом с ней.

2. Запусти Discord и игру с одинаковыми правами

Если игра запущена от администратора, а Discord нет (или наоборот) — Discord её не видит.

Закрой Discord полностью (значок в трее → Выйти) и запусти оба одинаково: оба обычно или оба «От имени администратора».

3. Переключи аппаратное ускорение

Настройки → Дополнительно → «Аппаратное ускорение» — выключи (если было включено) или включи (если было выключено). Discord перезапустится.

4. Окно вместо полного экрана

Чёрный экран в демонстрации чаще всего из-за эксклюзивного полноэкранного режима. В настройках игры поставь «Полноэкранный в окне» / Borderless.

5. Ноутбук с двумя видеокартами

Чёрный экран на ноутбуке = Discord и игра работают на разных видеокартах.

Параметры Windows → Система → Дисплей → Графика → добавь Discord.exe и игру → для обоих одинаковый вариант (лучше «Высокая производительность»).

Discord.exe лежит в %LocalAppData%\Discord\app-x.x.xxxx\.

6. Кодек и захват

Настройки → Голос и видео → раздел «Видеокодек» / «Демонстрация экрана»:

  • переключи «Использовать новейшую технологию для захвата экрана» (вкл ↔ выкл);
  • выключи «Аппаратное ускорение H.264», если включено.

7. Звука из игры нет в стриме

Discord передаёт звук только у демонстрации окна приложения, не всего экрана (на старых версиях Windows). Выбирай в демонстрации именно окно игры.

8. Ничего не помогло — чистая переустановка

  1. Удали Discord через «Приложения».
  2. Нажми Win+R → %AppData% → удали папку discord.
  3. Win+R → %LocalAppData% → удали папку Discord.
  4. Скачай Discord заново с discord.com.

В 9 случаях из 10 помогает шаг 2, 4 или 5.
