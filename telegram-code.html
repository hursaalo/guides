Telegram — не приходит код входа

SMS, звонок, QR, лимит попыток, заблокированный номер.

Сначала проверь, куда пришёл код

  • Код почти всегда приходит не по SMS, а в сам Telegram — на другое устройство, где ты уже вошёл (телефон, ПК, планшет, веб-версия). Ищи чат «Telegram» с синей галочкой.
  • Если код ушёл на старое устройство, к которому нет доступа — смотри раздел «Нет доступа к другим устройствам».

Если нужно именно SMS

  1. На экране ввода кода подожди таймер (1–2 минуты).
  2. Нажми «Не получили код?» → «Отправить SMS» или «Позвонить».
  3. Звонок: робот продиктует код, или придёт звонок с номера — последние цифры номера и есть код.
  • Если кнопки SMS нет: Telegram всё чаще предлагает вход через почту или Telegram Premium-подписку для SMS. Это нормально, это не взлом.

Код вообще не приходит — по шагам

  1. Проверь номер: код страны +7 для России, без лишней 8 в начале.
  2. Включи и выключи авиарежим, проверь, что SIM ловит сеть и приходят обычные SMS.
  3. Отключи VPN и прокси на время входа — с ними Telegram часто не шлёт SMS.
  4. Запроси код не чаще раза в 2–3 минуты. После 5–6 попыток Telegram блокирует отправку на несколько часов (сообщение «Too many attempts» / «Слишком много попыток»). Тогда только ждать — 8–24 часа.
  5. Попробуй войти с другого приложения: телеграм для ПК (desktop.telegram.org) или web.telegram.org — иногда там предлагают вход по QR.

Вход по QR-коду (если Telegram открыт на телефоне)

  1. На ПК открой Telegram Desktop или web.telegram.org → «Войти по QR-коду».
  2. На телефоне: Настройки → Устройства → «Подключить устройство» → наведи камеру.

Нет доступа к другим устройствам

  • Если был включён облачный пароль (двухэтапная аутентификация) — после кода попросит его. Забыл пароль → «Забыли пароль?» → код придёт на почту восстановления.
  • Если нет ни кода, ни почты — после сброса пароля Telegram даёт войти через 7 дней ожидания. Не запрашивай сброс повторно, таймер начнётся заново.
  • Если пишет «Номер заблокирован» / «This phone number is banned» — напиши на recover@telegram.org: тема «Banned number», в тексте номер в формате +7… и коротко, что ты не нарушал правила. Ответ — от суток до недели.

Чтобы не повторилось

  • Настройки → Конфиденциальность → Облачный пароль + почта для восстановления.
  • Держи Telegram открытым на двух устройствах (телефон + ПК) — код всегда будет куда прийти.
  • Никому не пересылай код: «поддержка Telegram» в личке — всегда мошенники.
