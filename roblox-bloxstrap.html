Roblox — Bloxstrap: FPS, графика, курсор

Снять лимит 60 FPS и настроить клиент легально.

Bloxstrap — бесплатный open-source лаунчер для Roblox на ПК. Через него можно снять лимит 60 FPS, включить «лёгкую» графику, поменять курсор, звук «oof», шрифт и показать, в каком регионе сервер. Это не чит: игру он не меняет, только настройки клиента.

Установка

  1. Только официальный сайт: github.com/bloxstraplabs/bloxstrap → Releases → Bloxstrap-vX.X.X.exe. (Сайты «bloxstrap download free» с рекламой — подделки.)
  2. Запусти → Install. Теперь Roblox запускается через Bloxstrap автоматически.
  3. Меню Пуск → Bloxstrap Menu — там все настройки.

Снять лимит FPS

> С 2025 года Roblox оставил разрешёнными только часть Fast Flags. Если какого-то пункта ниже нет в меню или он не действует — значит, Roblox его закрыл; просто пропусти.

  1. Bloxstrap Menu → Fast Flags → «Framerate limit» → поставь 240 (или частоту своего монитора).
  2. В самой игре: Настройки → Максимальная частота кадров → выбери максимум (это официальная настройка Roblox, работает всегда).
  3. Отключи V-Sync в панели NVIDIA / AMD для RobloxPlayerBeta.exe.

Графика: слабый ПК

  • Fast Flags → Rendering mode → «Direct3D 11» (стабильнее всего).
  • Preferred lighting technology → «Voxel» — меньше теней, сильно больше FPS.
  • Disable post-processing (размытие, свечение) — Вкл.
  • В игре: качество графики — вручную, 1–3.

Графика: красиво

  • Lighting technology → «Future» (самый красивый свет, если игра это поддерживает).
  • В игре качество графики 8–10.

Внешний вид клиента

  • Mods → «Use old death sound» — вернуть звук oof.
  • Mods → Mouse cursor → «Old cursor» или свой .png.
  • Mods → Custom font — свой шрифт для всего интерфейса Roblox (файл .ttf).
  • Appearance → тема лаунчера и иконка.

Полезное

  • Integrations → «Query server location» — в углу показывает, в каком регионе сервер (если пинг 200+ — ищи другой).
  • Integrations → «Discord Rich Presence» — друзья видят, во что ты играешь.

Важно

  • Bloxstrap — легальный: Roblox не банит за него. Не путай с «экзекуторами» и «инжекторами» — вот за них бан и почти всегда вирусы.
  • После обновления Roblox Bloxstrap обновляется сам, перенастраивать ничего не нужно.
  • Удалить: Параметры Windows → Приложения → Bloxstrap → Удалить. Roblox вернётся к обычному запуску.
