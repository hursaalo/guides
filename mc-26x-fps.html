Minecraft 26.x — Fabric, Sodium и FPS-моды

Новая нумерация версий, установка и разбор вылетов.

Minecraft перешёл на новую нумерацию версий: вместо привычных 1.21.x теперь 26.x (например, Java Edition 26.3 «Wilderness Bound»). Из-за этого путаются и моды: «версия 1.21» уже не последняя. Здесь — как выбрать версию, поставить Fabric и FPS-моды и не словить вылет при запуске.

> Дополнение к гайду «Minecraft — FPS для серверов». Если сервер (например FunTime, HolyWorld) работает на 1.21.x или 1.16.5, играй той версией, которую просит сервер, а не последней.

1. Какую версию ставить

  • Для одиночной игры и новых серверов: последняя стабильная 26.3 (релиз 15 сентября 2026).
  • Для серверов: смотри на сайте сервера или в его лаунчере, какая версия нужна (часто 1.21.x или 1.16.5 в отдельных режимах).
  • Снапшоты (26.4-snapshot…) нестабильны: для игры на сервере и для модов их не берём.

2. Установка Fabric на 26.x

  1. Скачай установщик только с fabricmc.net/use/installer.
  2. В установщике выбери Client, в списке версий — 26.3 (или нужную), нажми Install.
  3. Открой папку модов: Win+R → %appdata%\.minecraft\mods (если папки нет — создай).
  4. В лаунчере выбери профиль fabric-loader-… с нужной версией игры.

3. FPS-моды для 26.x

Ставь на modrinth.com с фильтром: версия игры = твоя (26.3) и загрузчик = Fabric.

  • Fabric API — обязателен для остальных.
  • Sodium — главный буст FPS.
  • Lithium — ускорение логики.
  • FerriteCore — меньше памяти.
  • Entity Culling — не рисует скрытое.
  • ImmediatelyFast и ModernFix — по желанию.

Если для твоей версии мода ещё нет — подожди: после выхода новой версии игры моды обновляются не сразу. Не ставь «неподходящую» версию мода, игра не запустится.

4. Если игра вылетает

  1. Убери последний добавленный мод и запусти снова.
  2. Открой лог: %appdata%\.minecraft\logs\latest.log — внизу написано, какой мод вызвал ошибку.
  3. Проверь, что версия Fabric API и модов совпадает с версией игры.
  4. Java: лаунчер обычно ставит нужную сам. Если пишет «неподдерживаемая версия Java» — установи ту, что указана на странице игры, и выбери её в профиле.
  5. Обнови драйвер видеокарты.

5. Память и настройки

  • Профиль → JVM-аргументы: -Xmx4G при 8 ГБ ОЗУ, -Xmx6G при 16 ГБ.
  • Дальность прорисовки 6–10, частицы «Уменьшено», облака «Выкл», макс. FPS «Неограниченно».
  • Видео-настройки Sodium: включи всё в разделе «Производительность».

6. Безопасность

  • Моды и установщик — только с официальных страниц (Modrinth, fabricmc.net). «Сборки с читами» с неизвестных сайтов часто содержат стилер.
  • На серверах читы, X-Ray и «киллауры» — бан. Здесь только оптимизация и визуал.

Памятка

  1. Версия игры = версия сервера.
  2. Fabric + Fabric API + Sodium + Lithium.
  3. Все моды строго под ту же версию.
  4. Вылет → убери последний мод и смотри latest.log.
