Установка • Java Edition

  1. Скачай ZIP-файл пака и не распаковывай его.
  2. В Minecraft открой Options → Resource Packs → Open Pack Folder.
  3. Перемести ZIP-файл в открывшуюся папку.
  4. Вернись в игру и активируй пак.

Установка • Bedrock / Mcpe

  1. Скачай файл .mcpack.
  2. Открой его — Minecraft должен импортировать пак.
  3. Перейди в Settings → Global Resources и активируй его.

Полезные Советы

  • Паки 16x часто менее требовательны к системе.
  • При необходимости попробуй базовый пак вместе с оверлеем.
  • Снижение количества частиц может помочь повысить FPS.
