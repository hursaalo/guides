  • 📢 │ announcements

  • 🔗 │ useful-links

📁 Community

  • 💬 │ general

  • 📸 │ media
  • 🎨 │ art-and-creations
  • 💡 │ suggestions

  • 🎮 │ looking-for-group

  • ⚔️ │ valorant
  • ⛏️ │ minecraft
  • 🎯 │ other-games
  • 📊 │ clips-and-highlights

  • 🔊 │ Squad 2

🔊 │ Afk

  • 🔊 │ Music

📁 STAFF (только для модераторов)

  • 🛠️ │ staff-chat
  • 📋 │ mod-logs
  • 🎫 │ tickets
  • 🚨 │ reports

Рекомендуемые роли:

  • Owner
  • Admin
  • Moderator
  • VIP
  • Member
  • Unverified

Права:

  • Information каналы → только читать
  • Announcements → писать только staff
  • Staff категория → видна только staff+
