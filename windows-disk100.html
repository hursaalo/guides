Windows — диск загружен на 100%

Найти виновника и убрать тормоза.

Найди виновника (1 минута)

  1. Ctrl + Shift + Esc → Диспетчер задач → «Процессы» → нажми на столбец «Диск», чтобы отсортировать.
  2. Кто сверху — тот и грузит. Дальше по пунктам ниже.

Частые причины и решения

  1. Обновления Windows (Windows Update, «Узел службы») — дай доделать 20–40 минут и перезагрузи. Потом: Параметры → Центр обновления → «Приостановить» на неделю, если мешает играть.
  2. SysMain (Superfetch) — Win + R → services.msc → SysMain → Тип запуска «Отключена» → Остановить. На HDD часто сразу снижает нагрузку.
  3. Windows Search (индексирование) — то же: services.msc → «Windows Search» → Отключена. Поиск в меню станет чуть медленнее.
  4. Антивирус (Защитник: «Antimalware Service Executable») — проверка идёт в фоне. Добавь папку с играми в исключения: Безопасность Windows → Защита от вирусов → Параметры → Исключения.
  5. Автозагрузка — Диспетчер задач → «Автозагрузка» → отключи всё ненужное (лаунчеры, торренты, обновлятели).
  6. Torrent-клиент или Steam качает — проверь, не идёт ли загрузка.
  7. Файл подкачки — если мало ОЗУ (8 ГБ и меньше), диск грузит подкачка. Закрой браузер с кучей вкладок; решение надолго — добавить памяти.

Проверь сам диск

  1. Командная строка от администратора → chkdsk C: /scan.
  2. Скачай CrystalDiskInfo (бесплатно, crystalmark.info) → состояние «Хорошо» — норм, «Тревога» или «Плохо» — диск умирает, срочно сохрани файлы.
  3. Если стоит HDD под системой — 100% диска это его потолок. Лучшее решение — SSD (от 2–3 тыс. ₽ за 256–512 ГБ), ускорение в разы.

Быстрые доп. действия

  • Win + R → cleanmgr → Очистка системных файлов.
  • Параметры → Система → Питание → режим «Максимальная производительность».
  • Перезагрузка, а не «Завершение работы» — с включённым быстрым запуском Windows полностью не перезапускается.
